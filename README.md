# rooma

## EXECUTIVE SUMMARY 
Rooma is a high-performance, cross-platform accommodation ecosystem 
designed to bridge the gap between seekers and providers in the real estate and 
hospitality sectors. Developed by eLPi.dev, Rooma centralizes the discovery, 
booking and management of diverse housing needs – ranging from student 
hostels and short stay hotels to long-term residential rentals and property sales. 
By leveraging a single codebase for Android, iOS, Windows and macOS, 
Rooma offers a seamless, scalable solution to the fragmented accommodation 
market in emerging economies. 

## PROBLEM STATEMENT 
The current accommodation landscape is plugged by fragmentation, lack of 
transparency and high “search costs”. Key challenges include: 
• Information Asymmetry: Reliable data on available hotels, rental units, 
and houses for sale is scattered across informal WhatsApp groups, 
unreliable agents, and outdated websites. 
• High Transaction Costs: Seekers waste significant time and money on 
physical inspections of properties that do not match their requirements. 
• Inefficient Management: Property owners and hotel managers lack 
integrated, user-friendly tools to track real-time availability and manage 
multi-platform leads. 
• Lack of Trust: Informal brokerage often leads to overpayment, 
misinformation, and security concerns for both parties. 

## THE SOLUTION: ROOMA 
Rooma provides a “one-stop shop” for everything accommodation. Unlike 
existing niche platforms, Rooma integrates four core verticals into a single, 
intuitive interface: 
1. Hostels & Student Housing: Optimized for university towns. 
2. Hotels and Short-stays: Competitive discovery for travellers and 
business professionals. 
3. Residential Rentals: Long-term housing for families and professionals. 
4. Property Sales: A verified marketplace for the buying and selling of 
homes.

## TECHNICAL FRAMEWORK
Rooma is engineered for scalability and performance:
✓ Development Philosophy: Cross-platform development using Flutter and Dart to ensure feature parity across mobile and desktop environments.
✓ Frontend: Modern, responsive UI/UX designed for high-conversion and low-friction navigation.
✓ Backend & Data: A centralized RESTful API architecture with a PostgreSQL backbone for secure, high-concurrency data handling.
✓ Payment: MTN & Telecel Payment Gateways, Stripe.
✓ Storage: AWS S3
✓ Security: JWT-based authentication and role-based access control (RBAC) to protect user data and financial integrity. Hubtel SMS Gateway for user authentication upon signup.
